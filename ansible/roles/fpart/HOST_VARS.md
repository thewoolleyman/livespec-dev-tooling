# `fpart` — per-host values for the inventory's `host_vars`

**None.** The role installs one distribution package with no tunables, on
every host the legacy inventory names: `ci-pool.yml` reaches
`poweredge-xubuntu`, `gmktec-xubuntu` and `hp-xubuntu`, and `dev-host.yml`
reaches `vps`.

When and how to use the tool it installs is in
[`.ai/bulk-data-copies.md`](../../../.ai/bulk-data-copies.md).

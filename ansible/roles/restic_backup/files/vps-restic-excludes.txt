# restic --exclude-file for the VPS -> S3 backup.
#
# This mirrors the pruning done by services/arq-vps-root-snapshot (rsync
# filters) so the restic and Arq backups cover the same content. The two lists
# are PARALLEL (different syntaxes) and must be kept aligned by hand: if you add
# an exclude to arq-vps-root-snapshot.sh, add it here too, and vice versa.
#
# restic matching: a pattern with no "/" matches a base name anywhere in the
# tree; a pattern with "/" (or a leading "/") matches the full path; "**" spans
# directories; a leading "!" re-includes. See `restic help backup`.
#
# Two deliberate policies (mirror these in arq-vps-root-snapshot.sh):
#   * .git is backed up EVERYWHERE (never excluded).
#   * /data is backed up VERBATIM (the final "!/data" re-include below).

# --- VERBATIM: re-include everything under /data ----------------------------
# /data/projects (== ~/workspace symlink) holds the user's repos and must be
# backed up in full — .git, node_modules, .venv, build artifacts, everything.
# This "!" negation comes LAST, so it overrides every exclude above for any
# path under /data (verified: it re-includes dirs AND file-globs like *.pyc).
# NOTE: .git is intentionally NOT excluded anywhere (backed up host-wide).
